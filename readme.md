# Yield Earnings Calculator

Yield Earnings Calculator is a simple tool to calculate the earnings from the user's investments based on yearly yield and calculating the desired time on recurrent or fixed investment.

## Features

- Calculate yield earnings for both recurrent and fixed investments.
- Determine earnings over a custom time period.
- User-friendly interface for ease of use.

## Usage

Just open the [Page](https://yield-earnings-calculator.vercel.app/) of the project and use it.
Or visit the [GitHub Page](https://luna115-oncode.github.io/YieldEarningsCalculator/) of the project for testing the preview version.
